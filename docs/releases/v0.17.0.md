# v0.17.0 — Heating curve readings and seasonal display

The heating curve groups both water-temperature fields before the outdoor-temperature fields. It automatically plots the installation's current outdoor temperature on the curve, with dashed horizontal/vertical guides and a persistent numeric readout. Moving or tapping the chart selects a separate inspection point; its values remain visible after leaving the chart and during state updates. Changes to the four settings still produce an immediate local preview and require Apply before being sent.

The outdoor point represents the curve's water-temperature target at the measured outdoor temperature, not measured water temperature or the controller's effective target after offsets and overrides. Missing outdoor measurements are explicitly reported. Fahrenheit sensors are converted to Celsius.

Integration options now include **Display mode**: Heating (winter), Cooling (summer), or both. Mode-specific entity rows, graphs and controls are hidden reversibly. Shared measurements, domestic-hot-water preferences, measurement updates, history and automation entity IDs are retained. Selecting a display mode does not change the Panasonic operating mode. Existing installations default to showing both until configured. Manually hidden entities and later personal dashboard edits are preserved.

The card resource has a new versioned URL to avoid reusing an older cached card. Existing generated heating-curve cards acquire their installation's outdoor sensor automatically.

Validation: protocol/Home Assistant regression suite, frontend interpolation and write guards, seasonal visibility switching/restoration, current-point rendering and persistent chart inspection, responsive Chromium and WebKit checks in CI.
