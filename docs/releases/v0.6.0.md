**Dashboard update notice:** Upgrade to [0.6.1](v0.6.1.md) before updating an existing dashboard. Use `update: true` with that version to preserve existing cards. The original `overwrite: true` instruction below performs a full replacement and may remove custom energy/runtime cards; 0.6.0 did not save a dashboard backup.

Zone 1 heating curve controls and live visualization.

- Added four opt-in temperature controls for the heating curve: maximum/minimum water and outdoor temperatures, with clear Zone 1 names.
- Retained advertised FIN Set Default actions, write permission checks, and controller limits. Captured curve bounds: water 20–75 °C; outdoor −20 to +15 °C.
- Added a bundled responsive dashboard card. Edits redraw the curve immediately as a local preview; Apply sends only changed defaults. Endpoint labels and pointer/touch readout show the water temperature along the curve.
- Added automatic frontend registration and dashboard mapping using actual registered entity IDs. Read-only curves use sensors when controls are disabled; installations are kept separate.
- Added unavailable/invalid state handling, cross-field checks in the card, pending confirmation, and partial-write error reporting. Individual number controls remain independently editable.
- Added five Python tests, five Node.js tests, and Chromium interaction/responsive checks. Documented reference models and software versions.

Update through HACS, restart Home Assistant, enable experimental controls in the integration options, and regenerate the intended dashboard with `panasonic_cascade.populate_dashboard` and `overwrite: true`. This replaces custom cards in that dashboard. Reload the browser/app to load the bundled JavaScript.

Writes are sequential, not atomic. Earlier writes may succeed before a later failure. The graph shows configured defaults; schedules, overrides, and regulation mode can affect actual operation. Hardware writes and real phone delivery remain unverified. No heating settings are changed by installing the update.
