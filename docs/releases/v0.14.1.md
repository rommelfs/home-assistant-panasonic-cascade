# 0.14.1 — Avoid PV-charge interruptions on small grid fluctuations

Experimental prerelease.

A reference-installation audit found repeated PV-charge withdrawals on 53–67 W grid readings while the battery continued charging at several kW, with closely timed power-based WP starts/stops. The default small grid-import tolerance is now 100 W. Existing saved tolerances are preserved and should be adjusted explicitly where desired.

Existing automatic heat-pump-priority charges can hold the request while import above the small tolerance, up to a hard 500 W limit, is confirmed for 60 seconds. Recovery resets the timer; sustained import stops charging and import above the hard threshold stops immediately. The hard limit (100–500 W) and confirmation (15–120 seconds) are configurable. This deliberately permits a small amount of transient grid consumption.

Starts, explicit manual charges and sensorless tests receive no confirmation grace; export-only mode is unchanged. Battery discharge, exhausted battery reserve, stale/invalid feedback, temperature and controller guards remain immediate. Pending import never grants a new full block; only remaining bounded confirmation may cross a deadline. Restart restoration, original-offset ownership and the persisted restart cooldown remain effective. Meter readings and source-energy accounting are not altered.

Regression tests replay the observed small peaks, transient 405 W recovery, sustained import, threshold boundaries, deadline behavior, hard-guard overrides and restart recovery. The minimum hold remains a heating-request policy, not guaranteed compressor runtime.
