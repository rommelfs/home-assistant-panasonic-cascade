# v0.17.1 — Preserve nested custom-card entity maps

Fix an integration setup error introduced in 0.17.0 when an unrelated dashboard card stores nested dictionaries or lists in its `entities` mapping. Only string entity IDs are checked against the visibility filter; other custom-card configuration remains untouched.

Includes all heating-curve and seasonal-display improvements from 0.17.0. Validated with 276 Python tests, including a regression case reproducing the live dashboard structure.
