# v0.8.0 — Clear live values and a working desktop heating curve

- Shorten generated temperature, power, energy and control labels across cards and graphs. Refresh stored default card labels, not just entity defaults.
- Dynamically hide unknown/unavailable rows in native live-value cards, including All values. Valid zero readings remain visible; recording and alarm processing are unchanged. Historical graphs retain past data.
- Prefer per-unit power summaries and the distinct plant total instead of repeating every mode register in the overview. Keep detailed mode registers under All values.
- Add **Momentanverbrauch** (current power) to Energy, separate from cumulative energy counters. Retain hourly/daily/weekly/monthly/yearly electricity-consumption charts.
- Add **COP aktuell** per heat pump and plant from same-snapshot thermal/electrical power. Normalize W/kW, reject missing/invalid/negative inputs and zero denominators. When optional unit summaries fail, use a complete heating-power pair if available. Do not combine mismatched pairs or invent readings. Display two decimals. This is instantaneous COP, not seasonal efficiency.
- Include outdoor temperature in the runtime power history and overview power history.
- Upgrade recognized single-installation storage dashboards containing an integration-owned curve card after startup. Back up before saving; retain layout, history ranges, custom cards and personal labels. Safe manual `update: true` remains available for other supported generated layouts.
- Move the curve module to `/panasonic_cascade/heating-curve-0.8.0.js?v=0.8.0`, retaining legacy and 0.7.0 routes. A fresh resource query restored the curve in Safari and the Home Assistant desktop app during live verification; the previous route was HTTP 200 but the client had not registered the element.

Update through HACS, restart Home Assistant and reload the client. Recognized generated dashboards update without replacement. For other layouts:

```yaml
action: panasonic_cascade.populate_dashboard
data:
  url_path: your-dashboard-path
  update: true
```

Validation: 121 Python tests, including COP units/zero/gap handling, short labels, dynamic card filtering, power deduplication, outdoor-temperature inclusion, and idempotent backed-up dashboard upgrades; Chromium and WebKit checks. No physical heat pump settings were changed during the live UI checks. Existing hardware-control and phone-delivery limitations still apply.
