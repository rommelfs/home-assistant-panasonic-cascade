Dashboard regression repair.

Version 0.6.0's documented replacement command could remove pre-existing/custom energy and runtime graphs: the generated dashboard did not recreate all those cards. This release changes the recommended update process and rebuilds the integration's energy/runtime content.

- Added `update: true` to `panasonic_cascade.populate_dashboard`. It preserves existing views, cards, graph settings, layout settings and custom entity labels while adding missing content. Repeated updates are idempotent; nested/sections layouts and single-card panel views are handled without replacing existing cards.
- Added electricity-consumption bar charts for hourly, daily, weekly, monthly and yearly periods. Only cumulative electrical-energy counters with long-term statistics are used; thermal generation and instantaneous power are excluded.
- Added cumulative energy and electrical/thermal power histories and a Runtime & cycling view with actual running-state timelines and compressor/working-hour counters.
- Fixed energy statistics graph discovery when current states are temporarily absent by consulting persisted entity capabilities.
- Added local backups before modifying existing dashboards, retaining up to five configurations per dashboard. Backup failures prevent replacement. Added `panasonic_cascade.restore_dashboard` to restore the latest saved configuration.
- Added eight regression tests, bringing the Python suite to 95 tests.

Update in HACS to 0.6.1, restart Home Assistant, then run:

```yaml
action: panasonic_cascade.populate_dashboard
data:
  url_path: panasonic-cascade
  update: true
```

Replace the URL path with your dashboard's actual path. Do not combine `update` and `overwrite`.

Backups begin with 0.6.1. This release cannot recover the exact configuration already overwritten by an older version; that requires a Home Assistant backup from before the replacement. The repair regenerates integration-provided charts without deleting other cards or changing entity IDs. It does not clear Recorder data, recreate missing historical measurements, change heat pump settings, or fabricate cycle counts.

The available statistics/Recorder history determines how much data each graph shows. Earlier hardware-write and phone-delivery limitations remain unchanged.
