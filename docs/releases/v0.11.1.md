# v0.11.1 — Explicit supervised charge test without buffer sensor

Add an opt-in **real hardware charge test** before the buffer temperature sensor is installed. This is not a simulation and has **no temperature cutoff**. Normal temperature-monitored charging is unchanged.

- Select the sensorless test in the PV configuration, leave the temperature source empty and keep automatic start off. Experimental controls, charge permission and explicit confirmation are still required.
- Manual starts raise the original offset by at most **2 °C**, within live controller limits and the overall 10 °C cap, for **at most five minutes**. The test overrides the ordinary offset setting; shorter requested durations remain shorter. Overlapping starts cannot extend the test.
- Fresh signed grid/battery/PV data, stable surplus, no grid import/significant battery discharge, heating mode and writable controller feedback remain required. No fake buffer temperature is introduced.
- Persist and restore the original default on stop, expiry, guard failure and restart. A failed restore remains pending and retries. **HA or network downtime can delay restoration beyond five minutes**; the controller has no verified local lease timer.
- Mark test operation and absent temperature cutoff clearly in status and the prominent overview card. Charge history retains the test marker as a state attribute.

After installing the actual sensor, select and verify it and disable the test checkbox before normal operation. Do not use the sensorless test for unattended heating.

Validation: 191 Python tests including a real local HA lifecycle with a simulated controller, plus frontend and CI validation. No physical heating commands were issued during development or publication.
