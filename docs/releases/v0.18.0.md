# v0.18.0 — Metering-cascade electricity accounting

Fixes source attribution when the heat pumps are outside EMMA's measured house/PV branch in a metering cascade. Choose **Configure electricity-source measurements → Metering topology → Metering cascade: EMMA in house branch, WP upstream**. The existing shared-boundary model remains available for systems whose meter includes the heat pumps.

In cascade mode, only positive export from the inner branch can supply the heat pumps. Remaining WP demand is grid supplied. Mixed PV/battery export is proportionally attributed and explicitly labelled an estimate; battery origin is never relabelled as PV. During inner-branch import, WP can be assigned to grid with valid WP/grid telemetry even if downstream PV/battery readings are missing. Export requires valid source telemetry and a plausible power balance.

WP consumption for the day, ISO week, month and year now comes from the same reset-aware electrical-counter statistics as the consumption charts, independently of attribution availability. Completed Recorder statistics intervals and controller-counter resolution determine freshness. These controller readings are not a calibrated external electricity meter. The dashboard separates total consumption, attributed energy, unmatched differences and observed attribution time.

**Attribution series restart.** Legacy and different meter/source mappings receive separate persistent ledgers and entity IDs. Previous source entities are hidden/disabled by the integration, with their data retained; they are not included in the corrected graphs. Update any personal automation that explicitly used previous source entity IDs. No historical PV/grid/battery proportions are invented or silently relabelled. The portion before cutover is shown as unassigned against retained WP counter totals. A source-mapping/topology change likewise isolates a new series; returning to the same mapping reuses that mapping's corrected ledger.

Frequent updates no longer continually postpone the delayed energy-ledger save. Clean shutdown still flushes it; abrupt power loss can lose the bounded unsaved interval.

Validation includes recorded regression cases: 2,504 W WP / 698 W inner-house import assigns 2,504 W to grid; 2,508 W WP / 122 W house export assigns 122 W from the house branch and 2,386 W from grid. Tests also cover mixed battery export, telemetry gaps, ledger isolation/reload, save scheduling, counter statistics, calendar boundaries and dashboard reconciliation. PV charging controls are unchanged.
