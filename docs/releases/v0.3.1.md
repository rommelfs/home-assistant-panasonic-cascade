New configuration option: use domestic hot water, under Settings → Devices & services → Panasonic Cascade / Smart Edge → Configure. Turning it off hides exclusively domestic-hot-water readings, controls, sterilization/legionella functions, COP, and availability status. Heating COP, the heating buffer, and zone controls remain available. This visibility option does not change controller configuration.

Existing entities are disabled and hidden internally to preserve IDs and user-assigned names. New domestic-hot-water entities are not created while the option is disabled. Existing native dashboard cards are cleaned automatically. Re-enabling restores entities and unchanged dashboards; subsequent user changes are not overwritten. Disabled entries remain discoverable in Home Assistant's full entity registry. YAML dashboards and custom cards with their own data formats may require manual updates.

The option applies independently to each installation and defaults to enabled for existing entries.
