Adds FIN username/password authentication and project selection.

- Setup now follows sign-in → project → site. Projects are discovered with secureEval(projs()). Multiple projects can be configured independently.
- SCRAM, legacy HMAC and server-requested plaintext mechanisms follow the captured FIN login client. Session cookies and the FIN attestation key are retrieved automatically and held only in memory.
- Explicit session expiry triggers one bounded login/retry. Access-denied responses do not cause a login loop.
- Existing cookie-based entries remain supported. Use Reconfigure to switch to username/password without replacing the project, site or entity IDs.
- 37 tests passed, including the RFC 7677 SCRAM vector, real loopback HTTP authentication, two-project selection, session renewal and the real Home Assistant 2026.10 config-flow classes with a fake backend.

Update the integration and restart Home Assistant. For existing entries, choose Reconfigure in the integration menu to enter username/password. New entries show project selection after sign-in.
