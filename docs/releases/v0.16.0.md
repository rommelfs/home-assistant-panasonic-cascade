# 0.16.0 — A compact dashboard with an at-a-glance first tab

Experimental prerelease. Adaptive PV charging from 0.15.0 is retained unchanged.

The first tab is now **At-a-glance**, with four native cards: current WP switching/running estimates, aggregate instantaneous electrical consumption plus today's recorded attributed energy, PV buffer permission/target/restoration status, and current alarms. Unknown critical feedback remains visible as unavailable; it is not converted to zero or an all-clear. No detailed control lists or full charts crowd the first tab.

Heating curves and controls move to **Steuerung**, temperature readings/history to **Temperaturen**, and full equipment values to the final **Diagnose** tab. **Laufzeiten & Taktung** retains the seven-day absolute starts table, on/off band, compressor hours and the power graph including outdoor temperature. Duplicate current-state/start-count cards and a redundant cumulative-hours plot are removed where the corresponding detailed table/band exists.

**Energie** keeps current power, COP, counters and a compact PV/grid/battery kWh balance for day, week, month, year and since setup. Five clearly labelled navigation buttons open native hourly/daily/weekly/monthly/yearly subviews, preserving consumption and source-attribution plots and their configured periods/time ranges. Links use the actual dashboard URL rather than a hardcoded path. A redundant cumulative-energy history plot is removed; energy counters, long-term statistics and recorder history are not changed.

Recognized generated dashboards are migrated through Lovelace's live storage API, with the previous configuration saved first. The original `overview` URL remains valid. Existing personal cards move intact to **Eigene Karten**; unrelated dashboards, single-card panel views, custom content and graph options are preserved. Repeating the migration does not add duplicates. The backup/restore action remains available.

Regression tests cover four-card structure, period navigation, custom-card and time-range preservation, repeated migrations, real Home Assistant template rendering and missing-data handling, alongside the protocol, lifecycle and adaptive-charge suite.
