Initial experimental integration for Panasonic Cascade Control / Smart Edge via the local FIN Haystack API.

- UI setup, site discovery, sensor and equipment status polling.
- Optional Set Default controls for SG Ready, quiet mode, buffer mode, zone selection and temperature setpoints.
- Session-cookie authentication, optional SkyArc attestation header and configurable certificate verification.
- 15 protocol/mock-transport tests passed; replayed 192 captured data grids containing 54 unique points.

This is a prerelease. Home Assistant runtime, real-controller connectivity and write operations have not been live verified. Username/password login is not implemented; browser sessions may expire. Controls are disabled by default. No credentials or HAR captures are included.

Install through HACS as a custom Integration repository, or copy custom_components/panasonic_cascade into Home Assistant's custom_components directory. See README for setup.

The GitHub Actions configuration is provided as validation-workflow.yml but is inactive because the publishing credential lacks workflow scope.
