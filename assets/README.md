# Integration artwork

`cascade-icon.svg` is original artwork for this community integration. It depicts two heat pump units connected in a cascade. It is not an official Panasonic or Home Assistant logo.

The raster versions are shipped in `custom_components/panasonic_cascade/brand/` as `icon.png` (256 × 256) and `icon@2x.png` (512 × 512). The artwork is covered by the repository's MIT license.
